# memory-game

## Описание проекта

Игра на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов. В случае прохождения, результат записывается в таблицу результатов.

## Локальный запуск

Требуется наличие Node JS. Порядок запуска:

 - `npm i`
 - `npm run dev`
 - dev server доступен по адресу по умолчанию: `http://localhost:5173/memory-game`
